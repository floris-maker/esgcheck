★ github.com/floris-maker/esgcheck

email security gateway detector

Find out which gateway is guarding an inbox.

Give it an email or a domain. It reads the domain's MX records and tells you whether inbound mail is screened by a third-party security gateway — Proofpoint, Mimecast, Barracuda and friends — or just handled by a native provider. The signal that decides whether your cold email ever lands.

What the verdict means

security gateway — screened hard native provider — standard filtering unknown — self-hosted / unrecognized no MX — can't receive mail null MX — refuses all mail

Run it live from your terminal

This page ships with baked MX data so it works offline in a sandbox. The command-line tool does real DNS lookups against any domain on earth.

$ pip install git+https://github.com/floris-maker/esgcheck
$ esgcheck john@ford.com
$ esgcheck acme.com --json
